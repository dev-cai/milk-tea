## 2. 充值金额选项

### 预设金额：
| 充值金额 | 赠送金额 | 到账金额 | 优惠说明 |
|---------|---------|---------|---------|
| 10元    | 0元     | 10元    | -       |
| 50元    | 5元     | 55元    | 送5元   |
| 100元   | 15元    | 115元   | 送15元（推荐）|
| 200元   | 40元    | 240元   | 送40元  |
| 500元   | 120元   | 620元   | 送120元 |
| 1000元  | 300元   | 1300元  | 送300元 |

### 自定义金额规则：
- 最低充值：10元
- 最高充值：10000元
- 赠送比例：
  - 50-99元：10%
  - 100-199元：15%
  - 200-499元：20%
  - 500-999元：24%
  - 1000元以上：30%

## 6. 交互逻辑

### 金额选择：
- 点击预设金额：选中该金额，清空自定义输入
- 输入自定义金额：清除预设金额选择
- 自动计算赠送金额和到账金额

### 支付方式：
- 默认选中微信支付
- 单选切换

### 提交充值：
1. 验证充值金额（10-10000元）
2. 验证协议是否同意
3. 显示确认弹窗
4. 调用充值接口
5. 更新用户余额
6. 返回上一页

---

## 7. API接口

### 充值接口：
```javascript
api.payment.recharge({
    userId: userInfo.id,
    amount: amount,        // 充值金额
    bonus: bonus,          // 赠送金额
    paymentMethod: 'wechat' // 支付方式
})
```

### 响应数据：
```json
{
    "code": 200,
    "message": "充值成功",
    "data": {
        "orderId": "123456",
        "amount": 100,
        "bonus": 15,
        "totalAmount": 115,
        "balance": 215.50
    }
}
```

## 8. 测试模式

### 开发测试：
- 当后端接口未实现时，会弹出测试模式确认
- 点击确认后模拟充值成功
- 直接更新本地用户余额
- 方便前端开发和测试

### 测试步骤：
1. 选择充值金额
2. 选择支付方式
3. 同意充值协议
4. 点击立即充值
5. 确认充值信息
6. 接口失败时选择"模拟充值成功"
7. 查看余额更新

## 11. 使用说明

### 用户操作流程：

1. **进入充值页面**
   - 从"我的"页面点击"充值"
   - 或从"会员中心"点击"充值"

2. **选择充值金额**
   - 点击预设金额（推荐100元）
   - 或输入自定义金额

3. **查看优惠**
   - 查看赠送金额
   - 查看到账金额
   - 了解充值优惠规则

4. **选择支付方式**
   - 默认微信支付
   - 可切换其他方式

5. **确认充值**
   - 勾选充值协议
   - 点击"立即充值"
   - 确认充值信息

6. **完成支付**
   - 跳转支付页面
   - 完成支付
   - 余额实时到账
