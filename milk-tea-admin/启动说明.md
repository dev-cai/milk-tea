# 管理后台启动说明

## 🚀 快速启动步骤

### 1. 安装依赖

首先确保已安装所有依赖，包括sass：

```bash
cd milk-tea-admin
npm install
npm install -D sass
```

### 2. 启动后端服务

在启动前端之前，**必须先启动后端服务**：

```bash
cd milk-tea-backend
mvn spring-boot:run
```

后端服务将在 http://localhost:8080 启动

### 3. 启动前端服务

```bash
cd milk-tea-admin
npm run dev
```

前端服务将在 http://localhost:3000 启动

### 4. 访问系统

打开浏览器访问：http://localhost:3000

默认登录账号：
- 用户名：`admin`
- 密码：`admin123`

## ⚠️ 常见问题

### 问题1：Sass依赖缺失

**错误信息**：
```
Preprocessor dependency "sass" not found. Did you install it?
```

**解决方法**：
```bash
npm install -D sass
```

### 问题2：API代理错误（ECONNREFUSED）

**错误信息**：
```
[vite] http proxy error at /api/xxx: AggregateError [ECONNREFUSED]
```

**原因**：后端服务未启动

**解决方法**：
1. 确保MySQL数据库已启动
2. 确保数据库已导入初始化脚本（database/milk_tea.sql）
3. 启动后端服务：
   ```bash
   cd milk-tea-backend
   mvn spring-boot:run
   ```

### 问题3：API模块导入错误

**错误信息**：
```
No matching export in "src/api/xxx.js" for import "default"
```

**解决方法**：
已修复，确保API文件包含默认导出。

### 问题4：端口被占用

**错误信息**：
```
Port 3000 is already in use
```

**解决方法**：
1. 关闭占用端口的程序
2. 或修改 `vite.config.js` 中的端口配置：
   ```javascript
   server: {
     port: 3001 // 改为其他端口
   }
   ```

## 📋 启动检查清单

在启动前端之前，请确认：

- [ ] Node.js 版本 >= 16.0.0
- [ ] npm 版本 >= 8.0.0
- [ ] 已安装所有依赖（npm install）
- [ ] 已安装sass（npm install -D sass）
- [ ] MySQL数据库已启动
- [ ] 数据库已导入初始化脚本
- [ ] 后端服务已启动（http://localhost:8080）
- [ ] 端口3000未被占用

## 🔧 开发环境配置

### 修改API地址

如果后端服务不在 localhost:8080，修改 `vite.config.js`：

```javascript
server: {
  proxy: {
    '/api': {
      target: 'http://your-backend-url:port',
      changeOrigin: true
    }
  }
}
```

### 修改前端端口

修改 `vite.config.js`：

```javascript
server: {
  port: 3000, // 改为你想要的端口
  open: true  // 自动打开浏览器
}
```
